# 💫 About Me:
👋 Hi, I'm **Sumit Asalkar** — a **Backend-Focused Developer, AI Engineering student, and SaaS enthusiast** passionate about building scalable systems, intelligent applications, and impactful real-world software. I enjoy turning ideas into production-ready solutions using **Flask, Spring Boot, REST APIs, PostgreSQL, MongoDB, JWT Authentication, secure architectures, and cloud deployment workflows**, while actively exploring modern full-stack development with **React.js**. Currently, I’m building a **multi-role Salon Management SaaS Platform** with **React.js + Spring Boot + PostgreSQL**, focused on authentication, appointment scheduling, staff & customer management, analytics, and business automation. Beyond SaaS systems, I’ve developed projects including an **E-commerce Platform**, **Fraud Reporting & Detection Portal**, **Courier Tracking System**, and **LLM + RAG-based Intelligent Retrieval Systems**, emphasizing **scalability, security, automation, and performance optimization**. As a **Software Developer Intern at Solven AI Solutions** and former **President of the AI Engineering Student Association**, I enjoy collaborating on technical solutions, leading innovation-driven activities, and continuously learning about **AI Systems, LLM Integration, RAG, SaaS Architecture, System Design, API Engineering, Database Optimization, and Secure Backend Development**. 🚀
